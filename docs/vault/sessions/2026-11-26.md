# Phiên 2026-11-26

## Mục tiêu
App remote desktop mã nguồn mở Android ↔ Windows (Vivobook S14 OLED → Tab S10+ / S26+), độ trễ thấp, có chế độ màn hình phụ qua USB (AOA).

## Đã làm
- Lõi Rust: rv-proto, rv-crypto (Noise XXpsk3 + OTP), rv-transport (FEC, discovery, path race, USB tether, TCP/443), rv-session, rv-usb-link (AOA host + ADB), rv-host-win (DXGI, OpenH264, WASAPI+Opus, input), rv-android-core (JNI → librv_core.so), rv-signal-relay.
- Android: decoder ladder Exynos/MTK, chẩn đoán toàn diện, stress test 1/2 phút, USB display mode, PIN.
- CI GitHub Actions + release `latest-build` (APK, rv-host.exe).

## Phát hiện
- spacedesk USB dùng AOA (accessory datronicsoft), KHÔNG phải tethering.
- S26+ bật USB tethering được → driver Windows ổn. Tab S10+ (Android 17) không bao giờ chuyển sang rndis → One UI từ chối; nghi spacedesk host chiếm AOA.
- Tab có c2.mtk.*.decoder.lowlatency; Exynos 2600 trần HEVC/H.264 403 fps @2800x1752 = 8K60 (giới hạn thiết kế, không phải bóp xung).

## Changes (core: proto/session/transport)
- Protocol v2 ([[decisions/ADR-0002-large-frames]]): u16 shard fields + FEC blocks (<=64 data shards, <=255 blocks, ~18 MB/frame); removed the ~290 KB limit. Tests: 3 MB @5% loss, 8 MB.
- Reconnect: `HostSession` accepts a new msg1 at any time (a live session is only replaced once the new msg3 verifies); msg1 rate limit 1/500 ms, `AttemptLimiter` per peer on OTP failures; `tick(now)` sends 1 s keepalives and declares disconnect after 5 s of silence (`HostSessionEvent::Disconnected`, `ClientEvent::Disconnected`).
- Codec signaling: `ControlMessage::StreamConfig`, `Keepalive`; android hello JSON `"codecs"` -> Hello mask (default h264); Kotlin gets state codes 4 (DISCONNECTED) and 11 (STREAM_CONFIG, "hevc 2800x1752@120 80000kbps") through the existing state callback.
